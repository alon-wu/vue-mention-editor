> 定位：基于 Tiptap 3 + Vue 3 的提及（@mention）编辑器组件库，以 npm 包的形式在 Vue 3 项目中直接使用。

## 〇、产品原则（默认值取向）

**mention 编辑器的 v-model 默认是文本，不是 HTML。** 这类组件的真实场景是聊天输入、评论框、AI 对话输入框——拿到一条能直接提交给后端 / 大模型的字符串才是主路径；`@` 出去的东西（人、标签、图片、技能、资料）以 `@ + id` 的形式留在文本里。

由此推出：

- `valueFormat` 默认为 `'text'`；提及时 token 用 `id`（稳定、可往返），展示信息由 `textValue.resolve` 还原；
- 想让值直接可读时可一处开关：`textValue.token: 'label'`（`@张三`），`resolve` 负责换回真实 id；`getText({ token })` / `getMarkdown({ token })` 可在任意地方取另一种形态；
- 解析时只认「行首或空格后」的 `@token`（`textValue.allowedPrefixes`），避免把邮箱等普通文本误判为提及；
- HTML / Markdown / JSON 是**扩展输出**：需要落库富文本、进 Prompt 或做结构化处理时，用 `getHTML()` / `getMarkdown()` / `getJSON()` 取；确实需要富文本值时再显式设 `value-format="html"`；
- 示例与文档一律**先展示文本值，再给扩展输出**。

## 三、工程与质量规范（P2）

### 代码

- **默认值取向**：v-model 默认文本（见第〇节）；演示扩展输出（HTML / Markdown / JSON）时必须显式声明这是扩展写法。
- props / emits / ref 方法 / 导出函数必须有 JSDoc；对外类型集中定义在 `src/types/index.ts`，组件内不重复声明 payload 类型。
- 组件内不出现魔法值：颜色、间距、圆角、层级一律走 `src/styles/tokens.css` 的语义令牌；示例走 `--demo-*` 令牌。
- VNode 透传统一用 `core/vnodeView.ts`（稳定组件 + clone），禁止 `<component :is="() => vnode" />` 这类每次渲染新建组件类型的写法。
- 触控/键盘可达性：面板支持 ↑↓ / Enter / Tab / Escape；编辑器 `role="textbox"`、`aria-multiline`。

### 示例（dev 画廊）

- 每个示例**只讲清一个能力点**，必须登记在 `dev/examples/index.ts`。
- 每个示例必须填写 `usage` 元信息，画廊统一渲染成「速览」面板：
  **绑定值 / 事件 / props / 插槽 / ref 方法 / 触发符配置 / 设计令牌 / 实现要点**。
  —— 回答「这个效果是怎么来的、用了什么、触发了什么」。
- 示例源码通过 `?raw` 展示，保证与实现永远一致；示例里出现的关键 API 名称必须与 `docs/` 一致。

### 文档

- `docs/` 分 `guide`（怎么用）与 `api`（有什么）：props、events、slots-methods、types、extensions。
- 需求变更（尤其 prop 改名）必须全量搜索同步 README / docs / dev / tests / CHANGELOG。

### 测试与校验

- `tests/` 覆盖行为而非实现：value 序列化、扩展配置、面板交互、编辑器事件、上限替换、悬浮提示。
- 每轮改动后执行：`bun run format:check && bun run typecheck && bun run test && bun run build`，并在浏览器把 18 个示例过一遍（控制台零报错）。

## 附录：原始需求原文（2026-09-20 收到，未删改）

```
是否满足以下需求：
1. 输入框是否可以自定义 placeholder 不仅支持普通字符串还要能支持 行内块组件
2. 输入框是否可以设置 最小多少行最大多少行，默认最小行高度，超过最小行没超过最大行时自动撑开高度，超过最大行时产生滚动条
3. 是否支持禁用
4. 是否能自定义提及候选列表的样式结构
5. 是否能自定义选中后的提及块的样式结构
6. 在 AI 项目中 @ 的是上传的图片/视频/音频/文件等资源 双向绑定的值不是html是 @+src 而且删除已上传的文件 @ 了相同的文件也需要删除
7. 在 AI 项目中 需要根据绑定的值恢复
整体检查是否满足，不满足整体调研设计实现
```
